# Minji Hunter

Play: https://minjidaddy.github.io/MinjiHunter-play/

Mobile portrait pixel platformer. This repository contains compiled game files only. Original development sources and source history are maintained in a separate private repository.

Sound defaults on; touch the screen to start audio. Defeated monsters drop coins and have a 30% chance to drop a full-heal potion. Walk over landed items to collect them. X: sword combo, Y: magic, A: jump (press again in the air for a double jump and a full turn at the apex), B: slide. START: pause, RESET: restart.
