# Minji Hunter

Play: https://minjidaddy.github.io/MinjiHunter-play/

Mobile portrait pixel platformer. This repository contains compiled game files only. Original development sources and source history are maintained in a separate private repository.

Touch the controls to start audio. X: sword combo, Y: magic, A: jump, B: slide. START: pause, RESET: restart.

Game artwork and sound assets are supplied for this game; their inclusion does not grant standalone redistribution rights. Phaser retains its own license.
